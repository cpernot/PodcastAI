G-U026-030_cap：G検定対策サマリー（U026〜U030）

この cap は、U026〜U030 の本文で扱った「学習を安定させ、過学習を抑え、更新を改善する」諸手法を、試験向けに整理し直したものである。

本文理解を前提として、ここでは用語の精密化、混同ポイントの切り分け、選択肢で問われやすい差分を圧縮して確認する。

1. このブロックの核

U026〜U030 の核は、ニューラルネットは逆伝播と勾配法だけで勝手にうまく学ぶわけではなく、出発点・過学習対策・分布調整・更新則の設計がそろって初めて安定して学習しやすくなるという理解である。

2. 最重要用語の定義

用語定義押さえるべき点
初期値設定学習開始時の重み・バイアスの与え方対称性を壊し、信号や勾配の大きさを保ちやすくする
Xavier 初期化主に sigmoid/tanh 系を想定した初期化法層をまたいでも分散が極端に変わりにくいようにする
He 初期化主に ReLU 系を想定した初期化法ReLU の性質に合わせて分散を調整する
正則化過学習を防ぐためにモデルの複雑さを抑える考え方汎化性能の改善が目的
L1 正則化重みの絶対値に罰則を加える重みが0になりやすく疎な表現を作りやすい
L2 正則化重みの二乗に罰則を加える重み全体を滑らかに小さく保ちやすい
重み減衰L2 的な抑制を更新へ反映する考え方大きな重みを抑える文脈で出る
Dropout学習時に一部ユニットをランダムに無効化する手法特定経路への依存を減らし過学習を抑える
Batch Normalizationミニバッチ統計で中間表現を正規化する手法学習安定化・高速化が主目的
SGDミニバッチごとの勾配で更新する基本手法最も素朴だが振動しやすい
Momentum過去の更新方向を残して慣性を持たせる手法ジグザグを抑えやすい
AdaGrad各パラメータごとに適応的学習率を与える手法学習率が縮みすぎることがある
RMSPropAdaGrad の縮みすぎを緩和した手法移動平均で勾配二乗を扱う
AdamMomentum と RMSProp 的発想を組み合わせた手法方向と歩幅を両方調整する代表手法

3. 混同しやすいポイント

混同しやすい組違い誤答しやすい形
初期値設定 vs 学習率初期値設定は出発点、学習率は歩幅どちらも学習の安定化に効くので役割を混同しやすい
L1 vs L2L1は疎、L2は全体を小さく均す「どちらも単に重みを小さくする」と雑に覚える
正則化 vs 過学習過学習は現象、正則化は対策両者を同義語のように読む
Dropout vs Batch NormalizationDropoutは落とす、BNは整えるどちらも“精度向上手法”として一括りにしてしまう
SGD vs 勾配降下法勾配降下法は上位概念、SGDはその代表的実装SGDだけが勾配法だと思う
Adam vs 最適化一般Adamは有力な一手法であって万能ではないAdamが常に最良と考える

4. 因果の流れで押さえる

このブロックは個別技術の寄せ集めではない。次の因果で理解すると記憶が安定する。

  1. まず、学習を始めるには初期値設定が必要である。
  2. 学習が進むと、表現力が高いモデルは過学習しやすい。
  3. そのため、L1/L2 や早期終了、Dropout などの正則化的手法が必要になる。
  4. 一方で、深いネットワークでは分布変動そのものが最適化を難しくする。
  5. そこで Batch Normalization が学習を安定化する。
  6. 最後に、勾配をどう更新へ変えるかという最適化手法の選択が効く。

5. 典型的な出題観点

  • 「同じ値で初期化すると何が問題か」→ 対称性が壊れず、ユニットが同じ振る舞いを学びやすい。
  • 「L1 と L2 の違い」→ L1 は疎性、L2 は滑らかな縮小。
  • 「Dropout はいつ適用するか」→ 通常は学習時で、推論時は全ユニットを使う。
  • 「Batch Normalization の目的」→ 主に学習安定化・高速化。
  • 「Adam の特徴」→ Momentum 的な方向調整と適応的学習率を組み合わせる。

6. ひっかけへの耐性

  • 「正則化 = L2 だけ」ではない。広義には Dropout や早期終了も過学習対策として含めて語られる。
  • 「Batch Normalization = 過学習対策」とだけ覚えると危険。主眼は学習安定化である。
  • 「Adam は必ず最良」は誤り。問題設定によっては SGD + Momentum が強い。
  • 「初期値は何でもよい」も誤り。初期化は学習のしやすさに影響する。

7. 実務目線の一段深い理解

現場では、これらの手法を単独で議論するより、組み合わせで考える。たとえば ReLU 系 + He 初期化 + Batch Normalization + Adam のように、各部品がそれぞれ別の問題を緩和する。

この視点を持つと、深層学習は「とにかくデータを入れれば学ぶ仕組み」ではなく、最適化上の難しさへ複数の工夫で対処している体系として理解できる。

8. 人に説明するなら

U026〜U030 は、ニューラルネットがうまく学ぶための“足回り”を扱っている。初期値でスタート地点を整え、正則化や Dropout で過学習を抑え、Batch Normalization で学習を安定させ、SGD や Adam などの最適化手法で更新の仕方を工夫する、という流れで捉えると全体がつながる。

9. 次ブロックへの接続

このブロックで学習の基礎的な安定化技術を押さえたことで、次のアーキテクチャ系ユニットに進む準備が整う。CNN や RNN などは、ここで見た最適化・正則化・初期化の知識を前提に理解すると、単なる用語暗記になりにくい。
