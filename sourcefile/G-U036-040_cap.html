G-U036-040_cap：G検定対策サマリー（U036〜U040）

この cap は、U036〜U040で学んだ CNNの中核部品（畳み込み・Pooling・画像認識の流れ）と、系列処理の基本（RNN・LSTM・GRU） を、G検定向けに再整理するための圧縮ユニットである。

通常ユニットでは理解の流れを重視したが、cap では 用語の定義、役割分担、混同しやすい論点、次ブロックの Attention / Transformer につながる因果 を短時間で確認できる形にする。

1. この cap の位置づけ

U036〜U038では画像向け深層学習であるCNNの発想を確認し、U039〜U040では系列向け深層学習であるRNN系を学んだ。つまりこの5ユニットは、データの性質に応じてモデル構造が変わる ことを理解するブロックである。

試験では、個々のモデル名を暗記するだけでなく、「なぜその構造が必要だったのか」を説明できることが重要になる。

2. この5ユニットの一本線

画像では、近くの画素の関係が重要なので、局所特徴を抜き出すCNNが自然だった。畳み込みが特徴を見つけ、Pooling が要約し、層を重ねることで高次特徴へ進む。

一方、文章や時系列では順序が重要なので、過去情報を引き継ぐRNNが必要になった。しかし単純RNNには長期依存の弱点があり、それを改善したのがLSTMとGRUである。

要するに、空間構造を使う発想がCNN、時間・順序構造を使う発想がRNN系 である。

3. 頻出用語の定義まとめ

用語定義の要点覚え方
畳み込み小さなフィルタを画像上で動かし、局所特徴の反応を得る操作小窓で模様を探す
フィルタ（カーネル）局所領域に適用する重みの集合模様検出器
特徴マップ各位置でフィルタがどれだけ反応したかの地図どこで特徴が強いか
Pooling近傍の値をまとめて要約する処理残す・圧縮する
RNN過去情報を内部状態に持ちながら系列を処理するネットワーク読み進めながら覚える
長期依存問題遠い過去の情報を後段で活かしにくい問題昔の情報が薄れる
LSTM / GRUゲートで情報の流れを制御し、RNNを改良した構造覚える仕組みを強化

4. G検定で混同しやすい点

混同しやすい組区別のポイント
畳み込み と Pooling畳み込みは特徴抽出、Pooling は要約・縮小
CNN と 画像認識全体CNNは画像向け構造であり、前処理・出力層・損失設計まで含めてタスクが成立する
RNN と LSTM/GRURNNは基本発想、LSTM/GRUはその長期依存改善版
位置ずれに強い と 位置不変Poolingなどで小さなずれに頑健になるが、完全に位置を無視するわけではない
系列を扱える と 長い系列を完璧に保持できる単純RNNは長期依存に弱い

5. 試験向けに押さえるポイント

  • CNN は 局所受容野・重み共有・階層的特徴抽出 が核心である。
  • Pooling は特徴をまとめ、位置ずれにある程度強い表現を作る。
  • RNN は系列順序を扱うための基本構造である。
  • LSTM / GRU は、単純RNNの長期依存問題への対策として登場した。
  • CNN と RNN 系は、データの構造の違いに応じた代表モデルとして比較できる。
  • 次の Attention / Transformer は、RNN系の限界を踏まえて理解するとつながりやすい。

6. 実務向けの補助理解

実務では、画像検査・外観判定ならCNN系、ログ列・時系列・文章ならRNN系やその後継手法、といった具合に、問題のデータ構造に応じて自然なモデル候補を考える。

また、現代ではTransformerが広く使われるが、その価値を理解するには、CNNやRNN系がどの課題に対して有効で、どこに限界があったのかを知ることが役立つ。

7. 3分で言い直すなら

U036〜U040では、画像と系列という異なるデータ構造に対し、なぜ異なるニューラルネット構造が発達したかを学んだ。CNNでは畳み込みが局所特徴を抽出し、Poolingがそれを要約して画像認識を支える。RNNでは系列の順序を扱うが、長期依存が苦手であり、それを改善したのがLSTMとGRUである。試験では、モデル名の暗記よりも、何の問題を解くためにその構造が必要だったか を一本線で説明できることが重要である。
