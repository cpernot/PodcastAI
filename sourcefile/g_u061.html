G-U061：Accuracy, Precision, Recall ― 指標の違いをどう捉えるか

Accuracy・Precision・Recall はどれも分類性能を測る指標だが、見ているものは同じではない。混同行列を土台に、それぞれが何を重視し、どの業務で効いてくるのかを整理する。

1. このユニットの位置づけ

前ユニットでは混同行列を見て、モデルの誤り方には種類があることを確認した。そこから自然に出てくるのが、何をもって「性能が高い」と言うのかという問題である。ここで最初に押さえるべきなのが Accuracy, Precision, Recall である。G検定では定義暗記だけでなく、どの場面でどの指標を重視すべきかを問われやすい。

特に現実の業務データでは、陽性が少ない、不正検知の見逃しが高コスト、アラートを出しすぎると運用が回らない、といった事情がある。したがって「正解率が高い」だけでは、評価として十分でない。

2. Accuracy（正解率）の意味

Accuracy は 全予測のうち何件を正しく当てたか を表す最も直感的な指標である。数式で書けば、(TP + TN) / (TP + TN + FP + FN) である。ここで TP は真陽性、TN は真陰性、FP は偽陽性、FN は偽陰性を表す。

Accuracy のよい点は分かりやすさにある。全体の中での当たり外れを一つの数字で示せるため、モデル比較の入口として便利である。しかし問題は、クラス不均衡に弱い ことである。たとえば陽性が 1% しかない検査データで、全部を陰性と予測しても Accuracy は 99% になる。これは性能が高いのではなく、単に多数派に寄りかかっただけである。

Accuracy は便利だが、「何を見逃してもよいか」を何も語ってくれない。見逃しが重大な医療・故障検知・不正検知では、Accuracy 単独評価は危険である。

3. Precision（適合率）の意味

Precision は 陽性と予測したもののうち、本当に陽性だった割合 であり、TP / (TP + FP) で表される。これは、モデルが「陽性です」と言ったとき、その主張をどれだけ信用できるかを示す指標である。

Precision を重視する場面では、偽陽性（FP）を減らしたい。たとえば迷惑メール判定で誤って重要メールを迷惑メール扱いすると困る場合や、広告配信で購買見込みなしの人に高コスト施策を打つ場合などは、陽性判定の質が重要になる。つまり Precision は、打った施策の無駄撃ちを抑えたいとき に効く。

Precision が高いということは「陽性だと言ったときの当たりの純度が高い」ことを意味する。陽性判定の信頼性を見る指標と捉えると理解しやすい。

4. Recall（再現率）の意味

Recall は 実際に陽性であるもののうち、どれだけ拾えたか を表し、TP / (TP + FN) で表される。これは取りこぼしの少なさを見る指標である。

Recall を重視する場面では、偽陰性（FN）を減らしたい。たとえばがん検診、製造ラインの重大欠陥検知、マネーロンダリング検知などでは、見逃しのコストが非常に高い。多少アラートが増えても、まず拾い切ることが大切になる。Recall は、重要事象をどれだけ網羅的に捉えたか を測る指標である。

指標何を見るか弱点向く場面
Accuracy全体の当たり外れ不均衡データに弱いクラス比率が大きく偏らない一般比較
Precision陽性予測の信頼性拾い漏れは見えにくい誤警報コストが高い場面
Recall陽性の拾い切り誤警報増加を許しやすい見逃しコストが高い場面

重要なのは、どれか一つが常に最良ではないことだ。モデル評価は、誤りのコスト構造 と結び付いて初めて意味を持つ。ここが G検定でも実務でも最も大事な視点である。

6. しきい値との関係

多くの分類モデルは内部で確率やスコアを出し、それに対して「0.5 以上なら陽性」といったしきい値を置いて判定する。このしきい値を動かすと Precision と Recall はトレードオフになることが多い。しきい値を厳しくすれば陽性判定は減り Precision は上がりやすいが、Recall は下がりやすい。逆に緩くすれば Recall は上がりやすいが、Precision は下がりやすい。

つまり、モデル性能は固定値ではなく、どの運用しきい値を採用するか で見え方が変わる。次のユニットで扱う F1-score や、その先の ROC 曲線・PR 曲線は、このトレードオフをより構造的に捉えるための道具である。

7. 実務での具体例

製造業の外観検査を考える。欠陥品を良品として流すと顧客クレームや回収につながるため、Recall が重要になりやすい。一方で、過剰検出が多すぎると再検査工数が膨らむため Precision も無視できない。結局は、Recall をある水準以上に維持した上で Precision を改善する、という二段階の見方が必要になる。

医療では見逃しのコストが特に重く、まず Recall が重視されやすい。広告や営業リード選別では、無駄撃ちコストを抑える観点から Precision が重要になりやすい。このように、指標選択は業務目的の翻訳である。

8. よくある誤解

  • Accuracy が高ければ性能が高い、というのは誤りである。
  • Precision が高いから Recall も高いとは限らない。
  • Recall が高いから陽性判定を信頼できるとは限らない。
  • 指標はモデル固有の絶対値ではなく、データ分布・しきい値・コスト構造に依存する。

試験では「陽性が少ない状況で Accuracy だけを見る危険性」や「Precision と Recall のどちらを優先すべきか」が典型的に問われる。

9. 試験ポイント

  • Accuracy は全体の正解率であり、不均衡データでは高く見えてしまうことがある。
  • Precision は陽性予測の純度、Recall は陽性の拾い切りを表す。
  • Precision は FP、Recall は FN と特に強く結び付く。
  • どの指標を重視するかは、誤判定のコスト構造によって決まる。

10. 人に説明するなら

Accuracy は全体でどれだけ当たったか、Precision は陽性だと言ったときの当たりの確かさ、Recall は本当に陽性なものをどれだけ拾えたかを表す。現実の業務では「何を見逃したくないか」「何を無駄撃ちしたくないか」で重視すべき指標が変わる。
