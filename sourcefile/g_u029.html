G-U029：Batch Normalization ― 学習を安定させる工夫

前回は Dropout を通じて、学習中にノイズを入れることで過学習を抑える発想を見た。今回は別方向の代表手法として、各層の分布を整え、学習を安定させる Batch Normalization を扱う。

Batch Normalization は、単に精度を上げる小技ではない。深いネットワークで学習が進みにくい理由の一つに、層をまたぐたびに信号の分布が変わり、最適化が難しくなることがある。BN はこの問題を和らげるための重要な仕組みである。

1. 今回の位置づけ

ここまで、初期値設定、正則化、Dropout を見てきた。これらは「出発点」「過学習抑制」「依存の分散」と、それぞれ違う観点から学習を改善する手法だった。Batch Normalization は、そこに層ごとの入力分布を整えるという視点を加える。

深いネットワークでは、前の層のパラメータが変わるたびに次の層へ入る値の分布も変わる。その結果、各層が常に変わる入力分布へ適応し続けなければならず、学習が遅くなったり不安定になったりする。BN はこの負担を軽減する。

2. 結論

Batch Normalization とは、ミニバッチ単位で各層の入力や中間表現を正規化し、その後に学習可能なスケール・シフトを加える手法である。これにより、学習を安定させ、比較的大きな学習率でも進みやすくなることが多い。

BN の主眼は、過学習抑制そのものよりも、最適化のしやすさと学習の安定化にある。

3. 何をしているのか

BN は、ある層に入る値について、ミニバッチ内の平均と分散を使って値を標準化する。これにより、その時点のバッチでは平均0、分散1に近いスケールへ整えられる。ただし、それだけだと表現力を制限しすぎるので、後段で学習可能な係数によって拡大縮小と平行移動を行う。

つまり BN は、単純に「全部同じ形にする」処理ではなく、扱いやすい分布へ一度整えたうえで、必要なら学習で適切な形へ戻せるようにしている。

4. なぜ学習が安定するのか

各層が受け取る値のスケールが大きく揺れると、同じ学習率でもある層では更新が激しすぎ、別の層では弱すぎる、といったことが起きやすい。BN はこの揺れを抑え、層ごとの最適化条件をある程度そろえることで、勾配法が働きやすい状態を作る。

その結果として、学習が速く進みやすくなり、初期値や学習率に対してやや頑健になることがある。G検定では厳密な理論論争よりも、「分布を整えて最適化しやすくする」という実務的理解が重要である。

試験での押さえ方：Batch Normalization は「ミニバッチ単位で正規化して学習を安定させる」手法であり、Dropout と主目的が異なる。

図で見る：Batch Normalization は各層でばらつく分布をいったん整え、学習しやすい状態にそろえる

5. 学習時と推論時の違い

BN は学習時には各ミニバッチの平均・分散を使うが、推論時には通常、学習中に蓄積した移動平均・移動分散を使う。もし推論時もその場の少数サンプルだけで正規化すると、出力が不安定になりうるからである。

この違いは Dropout にも似ているが、意味は別である。Dropout は学習時だけ落とすのに対し、BN は学習時と推論時で参照する統計量が違う。

6. Batch Size との関係

BN はミニバッチの統計量を使うため、バッチサイズが極端に小さいと統計が不安定になりやすい。この点は、Layer Normalization や Group Normalization など他の正規化手法が発展した背景ともつながる。

G検定では BN 自体が中心だが、少なくとも「バッチ依存の正規化である」という点は押さえておきたい。

7. Dropoutとの違い

両者は同じ深層学習の安定化文脈で出るが、発想はかなり違う。この区別が曖昧だと、試験で選択肢を誤りやすい。

8. 実務との接点

BN は画像系モデルなどで長く標準的に使われてきた。学習を速くしやすく、深いネットワークでも訓練しやすくなることが多いためである。一方で、Transformer 系や小バッチ学習では別の正規化法が使われることもある。

したがって、「正規化といえば必ず BN」ではなく、BN は特にミニバッチ統計を活用する代表手法だと捉えるとよい。

9. 他概念との関係

BN は、初期値設定や学習率調整を不要にするわけではないが、それらへの感度を下げることがある。最適化手法との組み合わせでも効果を発揮し、次ユニットで扱う SGD, Momentum, Adam などと合わせて、学習の進み方全体を形作る。

また、正則化的な副作用が語られることもあるが、中心はあくまで最適化しやすさである。

10. 試験ポイント

  • Batch Normalization は、ミニバッチ単位で平均・分散を使って正規化する。
  • 目的は主に学習の安定化・高速化である。
  • 学習時と推論時で用いる統計量が異なる。
  • Dropout は「落とす」、BN は「整える」と区別すると覚えやすい。

11. 人に説明するなら

Batch Normalization は、各層へ入る値のばらつきをミニバッチごとに整えて、学習を進めやすくする仕組みである。ネットワークが毎回大きく揺れる入力分布に振り回されにくくなるので、深いモデルでも安定して学習しやすくなる。
