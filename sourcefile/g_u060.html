G-U060：混同行列 ― 間違い方をどう見るか

分類モデルを評価するとき、正解率だけを見ても何をどう間違えたかは分からない。混同行列は、TP・FP・FN・TN を通じて誤りの構造を可視化し、Precision・Recall・F1 などの理解の土台になる。

このユニットの要点
  • 混同行列は『当たった割合』でなく『どの種類の誤りが起きているか』を見る道具である。
  • TP・FP・FN・TN を理解すると、Precision・Recall・F1 の意味が機械的でなく業務的に理解できる。
  • 不均衡データでは Accuracy だけでは危険で、混同行列が特に重要になる。

1. 今回の位置づけ

前回までで前処理、欠損値・外れ値、バイアスを見てきた。今回は、分類モデル評価の基礎となる混同行列を扱う。ここを押さえると、次ブロックの Accuracy、Precision、Recall、F1、ROC、PR 曲線へ自然につながる。

2. 結論

混同行列とは、予測結果と真のラベルの組み合わせを表形式で整理したものである。これにより、モデルが正しく当てた件数だけでなく、陽性を見逃したのか、陰性を誤って陽性と判定したのか、といった誤りの質が分かる。

重要：同じ Accuracy でも、見逃しが多いモデルと誤警報が多いモデルでは実務価値が大きく異なる。混同行列はその差を見せる。

3. TP・FP・FN・TNとは何か

記号意味日本語イメージ
TPTrue Positive陽性を陽性と正しく当てた
FPFalse Positive陰性なのに陽性と誤判定した
FNFalse Negative陽性なのに陰性と見逃した
TNTrue Negative陰性を陰性と正しく当てた

まずはこの4区分を、単なる英単語でなく業務上の意味で捉えることが大切である。病気検査なら FN は見逃し、迷惑メール判定なら FP は通常メールの誤排除、製造検査なら FP は良品の不良判定に相当する。

4. 混同行列の見方

二値分類では、縦横に真値と予測値を置いた 2×2 表として整理される。多クラス分類でも考え方は同じで、どのクラスをどのクラスへ誤分類しているかが分かる。

見るべき問い：

  • 陽性の見逃し（FN）は多いか
  • 誤警報（FP）は多いか
  • 特定クラス同士を混同していないか
  • 単に多数派クラスを当てているだけではないか

5. Precision・Recall・F1への接続

混同行列からは主要な評価指標が導かれる。ここで重要なのは、式暗記より意味理解である。

指標直感重視する場面
Precision陽性と予測したもののうち、どれだけ本当に陽性か誤警報を減らしたいとき
Recall本当に陽性のものをどれだけ拾えたか見逃しを減らしたいとき
F1Precision と Recall のバランス両方をそこそこ重視するとき

つまり、混同行列を読めれば、なぜ Precision を見るのか、なぜ Recall が重要なのかが自然に理解できる。逆に混同行列なしで指標だけ覚えると、実務で使い分けにくい。

6. Accuracyだけでは危ない理由

たとえば 1000 件中 990 件が陰性、10 件だけ陽性という不均衡データを考える。すべて陰性と予測しても Accuracy は 99% になる。しかしこのモデルは陽性を1件も見つけられない。つまり、Accuracy だけ見ると高性能に見えても、実際には役に立たないことがある。

注意：不均衡データでは Accuracy は簡単に高く見えてしまう。だからこそ TP・FP・FN・TN を見て、何ができていないかを確認する必要がある。

7. 実務での読み方

  • 医療：FN が重大。病気を見逃さないことが優先されやすい。
  • スパム判定：FP が重大。通常メールを消すのは困る。
  • 製造検査：FP は歩留まり低下、FN は市場流出につながる。
  • 不正検知：FN は見逃し、FP は調査コスト増になる。

このように、どの誤りを重く見るかは業務文脈で変わる。そのため、混同行列は単なる数学表でなく、業務コスト表に近い意味を持つ。

8. 他概念との関係

  • バイアス：群ごとに混同行列を比較すると不公平を見つけやすい。
  • 評価指標：次ブロックの Accuracy / Precision / Recall / F1 の土台。
  • しきい値調整：閾値を動かすと FP と FN のバランスが変わる。
  • PR曲線やROC：しきい値を動かしたときの挙動を可視化する発展版。

9. 試験ポイント

  • 混同行列は分類の誤り方を整理する表である。
  • TP・FP・FN・TN の意味を業務例と結び付けて理解する。
  • 不均衡データでは Accuracy だけで評価してはいけない。

10. 次回への橋渡し
