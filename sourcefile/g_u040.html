G-U040：LSTMとGRU ― なぜ改良が必要だったのか

U039で見たように、RNNは系列データを扱う基本発想として重要である。しかし、系列が長くなると昔の情報がうまく残らず、学習も難しくなるという問題があった。

そこで登場したのが LSTM（Long Short-Term Memory） と GRU（Gated Recurrent Unit） である。G検定では、細かい数式よりも、なぜ改良が必要で、どういう方向で改善したか を押さえることが重要になる。

1. 今回の位置づけ

このユニットは、RNNブロックのまとめにあたる。単純なRNNの限界を踏まえ、それを改善するための代表的構造としてLSTMとGRUを学ぶ。

次のU041以降では Attention と Transformer へ進むため、ここでは「RNN系が何を苦手としていたか」をはっきりさせておくことが重要である。

2. 結論

LSTM と GRU は、単純なRNNで起きやすい 長期依存問題 を緩和するために、情報を残す・忘れる・通すといった制御を明示的に組み込んだ改良型である。

つまり、何でも内部状態に流し込むのではなく、必要な情報だけを維持し、不要なものを捨てる仕組み を持たせた点が本質である。

3. 長期依存問題とは何か

長期依存問題とは、系列のかなり前に出てきた情報が、後ろの時点の解釈に必要であるにもかかわらず、途中でその情報が弱まり、うまく利用できなくなる問題である。

たとえば長い文章で主語が前半にあり、後半の動詞解釈に影響するような場合、遠い過去の情報を保持できないと意味理解が難しくなる。

学習の文脈では、長い系列を逆向きにたどると勾配が小さくなりやすい・大きくなりすぎるといった問題も関わる。ここではまず、昔の情報を維持しにくい という直感で押さえればよい。

4. LSTM の発想

LSTM は、単純な内部状態だけでなく、比較的長く保持しやすいセル状態を持ち、そこに対してゲートで情報の流れを制御する。

よく説明されるのは、入力ゲート・忘却ゲート・出力ゲートである。重要なのは名前の暗記より、入れるか、残すか、出すかを切り分けて制御する 発想である。

入力ゲート新しい情報をどれだけ取り込むか
忘却ゲート過去情報をどれだけ残すか捨てるか
出力ゲート現在の出力としてどれを表に出すか

5. GRU の発想

GRU は、LSTM よりやや簡潔な構造で、更新ゲートやリセットゲートを使って情報の流れを制御する。LSTMより部品数が少なく、計算が比較的軽いとされる。

G検定では、GRU は「LSTMを簡潔化した改良型」と捉えておけばよい場面が多い。

6. LSTM と GRU の違い

両者とも、単純RNNより長期依存に強いという目的は共通している。違いは内部構造の複雑さとゲートの設計にある。

実務では、性能・計算量・実装都合で使い分けることがあるが、試験では「どちらもゲート機構で系列情報の保持を改善する構造」であることが重要である。

比較観点LSTMGRU
構造やや複雑比較的簡潔
代表的部品セル状態 + 複数ゲートより少ないゲート構成
押さえるべき本質長期依存を扱いやすくする同左

7. なぜそれでも次の世代が必要だったのか

LSTM や GRU により、単純RNNの弱点はかなり改善されたが、系列がさらに長くなったり、並列計算効率や遠距離依存の扱いで限界が見えてきた。

その先で登場するのが Attention や Transformer である。つまり、RNN → LSTM/GRU → Attention/Transformer には、系列の遠い関係をどう効率よく扱うか という一貫した問題意識がある。

「LSTMが出たからRNNの問題は完全解決」とは考えないこと。後続技術は、さらに別の観点から限界を乗り越えようとしている。

8. 実務との接点

実務では、長めの時系列や文脈依存があるデータで、単純な逐次モデルでは性能が伸びない場合に、LSTM や GRU のような改良型を検討する発想がある。

また、現在主流のTransformerを理解する際も、LSTM/GRUが何を改善したのかを知っておくと、新旧モデルの違いを構造的に説明しやすい。

11. 試験ポイント

  • LSTM と GRU は、単純RNNの長期依存問題を緩和する改良型 である。
  • 改良の本質は、ゲート機構により情報の流れを制御する点にある。
  • LSTM はやや複雑、GRU は比較的簡潔な構造である。
  • 両者の共通目的は、遠い過去の情報をより扱いやすくすることにある。
  • それでも限界があり、次に Attention / Transformer が重要になる。

12. 人に説明するなら

LSTM と GRU は、系列データのかなり前に出てきた情報を残しやすくするために、情報の出入りをゲートで制御する改良型RNNである。単純RNNより長期依存に強いが、さらに長い依存や計算効率の問題から、次世代としてAttentionやTransformerが注目される。
