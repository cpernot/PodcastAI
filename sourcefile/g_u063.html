G-U063：ROC曲線とAUC ― しきい値全体で見る

しきい値を一つに固定すると見えない性能差がある。ROC 曲線と AUC は、分類モデルのランキング能力をしきい値全体で捉えるための基本道具である。

1. このユニットの位置づけ

Accuracy, Precision, Recall, F1-score はいずれも、ある一つのしきい値を前提にした指標である。しかし分類モデルが出すのはしばしば連続的なスコアであり、運用上はどこで閾値を切るかをあとから決めることが多い。そこで必要になるのが、しきい値全体で性能を見る 見方である。

ROC 曲線と AUC は、その代表的な道具である。G検定では定義だけでなく、何を横軸・縦軸に置くのか、不均衡データではどんな注意が必要かが問われやすい。

2. ROC 曲線とは何か

ROC は Receiver Operating Characteristic の略であり、しきい値を連続的に動かしたときの性能の変化を描く曲線である。横軸に 偽陽性率（FPR）、縦軸に 真陽性率（TPR = Recall） をとる。

FPR は FP / (FP + TN)、TPR は TP / (TP + FN) である。しきい値を緩くしていけば陽性判定が増えるので TPR も FPR も上がりやすく、厳しくしていけば両方下がりやすい。ROC 曲線は、その全体の軌跡を示している。

3. 曲線の読み方

理想的なモデルは、FPR を低く保ちながら TPR を高くできるため、ROC 曲線は左上に張り付く。逆にランダム分類に近いモデルは対角線付近を通る。したがって ROC 曲線は、どれだけ低い誤警報で高い検出率を実現できるか を可視化する道具だと言える。

左上に近いほどよい、対角線に近いほどランダムに近い、という直感を押さえておくと試験問題に強い。

4. AUC の意味

AUC は Area Under the Curve の略で、ROC 曲線の下の面積を表す。値が 1 に近いほど望ましく、0.5 付近ならランダムに近い。AUC は、しきい値を一つに固定せずにモデルのランキング能力を要約した指標と考えられる。

より直感的には、陽性サンプルが陰性サンプルより高いスコアを得る確率に近い解釈ができる。つまり AUC は、モデルがサンプルをどれだけうまく序列化しているかを見る指標である。

5. ROC/AUC の利点

利点は、しきい値依存を減らして比較できる点にある。運用前のモデル比較や、業務側としきい値調整をこれから決める段階で有用である。また TPR と FPR の関係を見るため、検出率と誤警報率のバランスを俯瞰しやすい。

特に同じ Accuracy でも ROC 曲線の形が異なることは珍しくない。したがって ROC/AUC は、表面的な正解率では見えない分類能力の差を示してくれる。

6. 不均衡データでの注意

ただし、強いクラス不均衡では ROC/AUC だけでは十分でないことがある。陰性が非常に多いと、FPR が小さく見えやすく、誤検出の実数的な多さが直感に乗りにくい。そのため、陽性が希少な問題では次ユニットの PR 曲線の方が有用になる場合がある。

ROC/AUC が高いからといって、希少陽性問題でそのまま運用しやすいとは限らない。不均衡データでは PR 曲線との併用が重要である。

7. しきい値選定との関係

ROC 曲線は最終的なしきい値そのものを教えてくれるわけではない。むしろ、複数候補のしきい値に対して、どんな TPR/FPR の交換関係が起こるかを見せてくれる。ここから「この業務なら誤警報を何件まで許容できるか」「見逃し率を何%以下に抑えたいか」を考えて、しきい値を決めていく。

したがって ROC/AUC は、運用要件の前段階にある比較・設計用の道具 と捉えると分かりやすい。

8. 実務での具体例

製造ラインの異常検知で、初期段階では候補モデルを比較する必要がある。このとき ROC/AUC は、しきい値をまだ決め打ちせずにモデルの「異常を上位に押し上げる力」を比較するのに向いている。一方で運用導入段階では、具体的な再検査工数や見逃しコストを考え、しきい値を詰める必要がある。

つまり ROC/AUC は、モデル選定 に向くが、運用値の最終確定 には追加情報が必要である。

9. 試験ポイント

  • ROC 曲線は横軸 FPR、縦軸 TPR をとる。
  • AUC は ROC 曲線下の面積で、しきい値全体でのランキング能力の要約である。
  • 曲線が左上に張り付くほど望ましい。
  • 不均衡データでは PR 曲線の方が実務的に重要なことがある。

10. 人に説明するなら

ROC 曲線は、しきい値を変えたときに「どれだけ拾えて、どれだけ誤警報が出るか」の全体像を示すグラフである。AUC はその性能を一つの数値にまとめたもので、モデルのスコア付けのうまさを表す。
