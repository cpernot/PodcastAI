G-U062：F1-score ― PrecisionとRecallの両立を見る

F1-score は Precision と Recall を一つにまとめる代表指標である。ただの式暗記ではなく、なぜ調和平均なのか、どんな場面で有効でどこに限界があるのかまで押さえる。

1. このユニットの位置づけ

前ユニットで見たように、Precision と Recall はしばしばトレードオフになる。そこで登場するのが F1-score である。これは二つの指標を一つにまとめるための代表的な方法であり、G検定でも頻出である。

ただし、F1-score は「万能の総合指標」ではない。何を平均しているのか、なぜ算術平均ではなく調和平均なのか、どのような局面で有効でどこに限界があるのかまで理解しておく必要がある。

2. F1-score の定義

F1-score は Precision と Recall の 調和平均 であり、2PR / (P + R) で表される。ここで P は Precision、R は Recall を表す。

調和平均が使われる理由は、どちらか片方だけが高い状況を厳しく見るためである。たとえば Precision が高くても Recall が極端に低ければ、実務上は役に立ちにくい。算術平均だと片方の高さが他方の低さを隠しやすいが、調和平均はそのバランスの悪さを反映しやすい。

図で見る：F1-scoreはなぜ調和平均なのか

3. なぜ調和平均なのか

Precision=1.0, Recall=0.1 の場合を考える。算術平均は 0.55 だが、F1-score は約 0.18 になる。後者の方が「片寄った性能」をより厳しく表している。これは、モデル評価で重要なのが、単なる平均点ではなく 両方をある程度満たしているか だからである。

F1-score は「Precision と Recall の両立度合い」を表す。どちらか一方だけを極端に良くしても、高得点になりにくい点が本質である。

4. どんな場面で使うか

F1-score は、陽性が少ない不均衡データや、Precision と Recall の両方が重要な場面で使われやすい。たとえば製造不良検知では、見逃しも困るし誤検出で再検査が増えすぎても困る。そうした局面では、F1-score を一つの代表値として採用しやすい。

一方で、見逃しのコストが極端に高い医療スクリーニングでは Recall をより重く見るべきことがあるし、営業施策の無駄撃ちが極端に高い場合は Precision をより重く見ることがある。このような場合、F1-score だけで意思決定するのは危険である。

5. Fβ-score との関係

F1-score は Precision と Recall を同じ重みで扱うが、現実にはどちらかをより重視したいことがある。そのときに使うのが Fβ-score である。β が大きいほど Recall を重視 し、β が小さいほど Precision を重視する。

G検定では細かな式変形よりも、「F1 は両者を等重視した代表例」「必要に応じて重みを変える拡張がある」という理解が重要である。つまり指標は一枚岩ではなく、目的に応じて設計するものだということが分かればよい。

6. F1-score の限界

F1-score は便利だが、真陰性（TN）を直接見ない。そのため、陰性を正しく判定する重要性が高い場面では情報が落ちることがある。また、確率出力の品質やしきい値全体での性能も分からない。これが次の ROC 曲線や PR 曲線、キャリブレーションへつながる理由である。

F1-score は「Precision と Recall の要約」であり、モデルの全性能を網羅する指標ではない。要約した分だけ捨てている情報がある。

7. 混同行列との接続

F1-score は混同行列から導かれる指標群の一つである。TP, FP, FN をもとに Precision と Recall を計算し、そこから F1-score が出る。したがって、混同行列を読めないと F1-score の意味も曖昧になる。

ここで重要なのは、混同行列 → Precision / Recall → F1-score という階層で理解することである。後半の指標ほど抽象化されていて便利だが、土台は混同行列にある。

8. 実務での使い方

モデル選定の初期段階では F1-score を比較軸にしやすい。しかし運用設計では、実際には Precision と Recall を分けて確認するべきである。F1-score が同じでも、Precision 高・Recall 低のモデルと、その逆のモデルでは運用影響が大きく異なるからだ。

つまり F1-score は 比較のための圧縮指標 として有用だが、現場実装では元の指標に戻って考える必要がある。

9. 試験ポイント

  • F1-score は Precision と Recall の調和平均である。
  • どちらか一方だけが高い状況を厳しく評価する。
  • F1-score は TN を直接見ないため、万能ではない。
  • β を変えることで Precision と Recall の重み付けを調整できる。

10. 人に説明するなら

F1-score は、Precision と Recall を一つの数値にまとめた指標である。片方だけ高い状況では高得点になりにくく、「陽性判定の質」と「陽性の拾い切り」の両立度合いを見るのに向いている。
