G-U064：PR曲線 ― 不均衡データで何を見るか

陽性が希少な問題では、ROC だけでは実感とずれることがある。PR 曲線を用いると、拾い切りと陽性判定の純度をより直接に評価できる。

1. このユニットの位置づけ

前ユニットでは ROC 曲線と AUC を見た。そこでは TPR と FPR を軸に、しきい値全体での性能を評価した。しかし陽性が非常に少ない不均衡データでは、FPR が見かけ上小さくても実際の誤警報件数が無視できないことがある。そこで重要になるのが PR 曲線 である。

PR 曲線は、希少陽性問題で「拾えているか」と「拾ったものをどれだけ信頼できるか」を直接見る道具である。G検定では、ROC と PR の使い分けが問われやすい。

2. PR 曲線とは何か

PR 曲線は横軸に Recall、縦軸に Precision をとる。しきい値を動かしながら、陽性の拾い切りと陽性予測の純度の関係を描く。Recall を上げようとすると Precision が落ちやすく、Precision を上げようとすると Recall が落ちやすい。PR 曲線はこのトレードオフを可視化したものだ。

ROC 曲線が TPR と FPR を見るのに対し、PR 曲線は 陽性をどれだけ拾い、その結果どれだけ当たりが含まれているか を直接見る。だから陽性が希少な問題では理解しやすい。

3. なぜ不均衡データに向くのか

陽性がごく少ない場合、陰性の総数が非常に大きいため、FP がある程度出ても FPR は小さく見えやすい。その結果、ROC 曲線では悪く見えないモデルでも、実際には誤警報が多すぎて使いにくいことがある。PR 曲線は Precision を使うため、陽性判定の純度低下がより直接に反映される。

希少陽性問題では「どれだけ拾えたか」だけでなく、「拾ったものの中にどれだけ当たりがあるか」が重要である。PR 曲線はそこを正面から見ている。

4. 曲線の読み方

PR 曲線では右上に近いほど望ましい。Recall を上げても Precision を高く維持できるモデルは優れている。逆に Recall を少し上げただけで Precision が急落するモデルは、実運用で大量の誤警報を生みやすい。

基準線は陽性率に依存する点にも注意が必要である。陽性率が低いほど、ランダム分類の Precision は低くなる。したがって PR 曲線は、データセットのクラス比率と切り離して解釈できない。

5. ROC と PR の使い分け

両者は対立概念ではなく、見ている面が違う。したがって重要案件では両方を見るのが望ましい。

6. Average Precision との関係

PR 曲線の下の面積に相当する要約指標として Average Precision（AP）が使われることがある。これは複数のしきい値における Precision の情報を Recall 全体でまとめたものと捉えられる。G検定で深掘りされる頻度は高くないが、PR 曲線にも AUC 的な要約があると知っておくと理解が整理しやすい。

7. 実務での具体例

不正取引検知では陽性率が非常に低いことが多い。この場合、ROC/AUC が高くても実際にアラートを出すと誤警報だらけになることがある。PR 曲線を見ることで、Recall を高めたときに Precision がどこまで保てるかを確認できる。

製造不良の最終検査でも似た構図がある。重大欠陥を拾うため Recall を上げたいが、再検査工数が爆発すると運用不能になる。PR 曲線は、その境界を探るのに役立つ。

8. よくある誤解

  • PR 曲線は ROC 曲線の下位互換ではない。
  • PR が高いからといって ROC も必ず高いとは限らない。
  • 不均衡データなら必ず PR だけ見ればよい、というのも単純化しすぎである。

試験では「陽性が少ない問題では PR 曲線が有効」という基本を押さえつつ、ROC を完全に不要とみなさないことが重要である。

9. 試験ポイント

  • PR 曲線は横軸 Recall、縦軸 Precision である。
  • 不均衡データで有用になりやすい。
  • 陽性を拾う力と、陽性判定の純度を同時に見る。
  • ROC と PR は用途が異なり、使い分けが必要である。

10. 人に説明するなら

PR 曲線は、陽性をどれだけ拾えているかと、その陽性判定がどれだけ信用できるかの両方を、しきい値全体で見るグラフである。陽性が少ない問題で特に役立つ。
